Everything you copy — text, links, colours, files, images — stays on your machine, encrypted at rest with Windows DPAPI. One hotkey, find it, paste it into the right window, and never lose your place.

The Three Promises

🔒

Nothing leaves the PC

Local SQLite, DPAPI-encrypted content and images, no account, no network calls. Password-manager clips are ignored before they are ever stored.

local-onlyDPAPI
🎯

Never paste into the wrong window

Paste verifies the target owns the foreground before sending Ctrl+V. If it cannot prove the target, it copies instead of guessing.

target-verifiedSendInput
🧊

The list never jumps

New copies are saved in the background. The list you are reading stays exactly where it is, so "item 3" is always item 3.

Capture Flow

1
Clipboard changesWindows sends WM_CLIPBOARDUPDATE to ClipboardMonitor.
2
Self-write checkIf the app wrote the clipboard itself, stop — otherwise it would capture its own paste and loop.
3
Privacy filterIgnored apps and password-manager privacy flags are rejected before anything is read.
4
Format priorityFile drop → image → text → HTML → RTF. The richest safe representation wins.
5
Identity + dedupeType-prefixed SHA-256 decides whether this is new, a recopy, or a duplicate.
6
Store, do not rebuildThe entry is encrypted and saved. The visible list is marked stale but left untouched.

Paste Flow

1
Build payloadSingle entry, merged batch, or sequential queue — plain or rich.
2
Resolve targetThe previously active window is checked; a stale or invalid target opens the picker.
3
Write clipboardSelf-capture suppression is set for the duration of the write.
4
Verify foregroundIf the target does not own the foreground, the app copies and stays visible.
5
Keys releasedWaits out physical modifier keys so the synthetic Ctrl+V is not corrupted.
6
Send Ctrl+VRaw SendInput with a 40-byte x64 struct. Result checked before success is claimed.

Security Boundary

Clipboard history

Sensitive detection and ignored-app rules run before storage. Allowed content is encrypted with DPAPI CurrentUser, so the database is useless without the signed-in Windows account. Sensitive clips mask in the UI and expire automatically.

API key vault

AES-256-GCM records behind a DPAPI-wrapped vault key, with optional master password and timed unlock. Keys never enter history, search, or batch copy. Key material is zeroed when the vault closes.

Product Decisions

Landmines — Do Not Touch

Wishlist

Direction, not promises. Nothing here is built until the safety model above can be preserved.

Encrypted multi-device sync

Keep history on a second PC without a plaintext server copy. Must reuse the DPAPI/encryption layer end to end.

Not started

Plugin / script actions

Add explicit, permissioned actions to selected clips — without turning the app into a default scripting host.

Not started

Local OCR for screenshots

Search the words inside an image clip, processed locally with explicit opt-in and no cloud OCR.

Not started

Per-app capture rules

Richer rules than a simple ignore list — e.g. images only from a design tool, never text from a terminal.

Not started
